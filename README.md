# TOM ERP – Issues and Requests

This is where you report problems and ask for changes in **TOM ERP (production)**.
There is no source code here, only issues.

## How to report something

1. Open the **Issues** tab and click **New issue**.
2. Pick the form that fits:
   - **Bug report**: something is broken, shows an error, or gives the wrong result.
   - **Access problem**: you can't open a page, see a record, or use a button you need.
   - **Feature or change request**: you'd like something new or done differently.
   - **Question**: you're not sure how something works.
3. Fill in the form and click **Submit new issue**.

Search the existing issues first. If someone has already reported the same thing,
add a comment or a 👍 to it instead of opening a new one.

## What makes a good report

- **Where**: the module and page, and the page link copied from your browser.
- **Which record**: the document number, such as an invoice, sales order or PO number.
- **What you did**: the steps, in order, so we can repeat them.
- **What you expected** and **what actually happened**.
- **A screenshot**, especially of any error message. You can paste images straight into the form.

## Please don't post

- Passwords, one-time codes, or sign-in links.
- Bank account or card numbers, NRIC/FIN or passport numbers, or salary details.

Crop or blur these out of screenshots. If we need sensitive details to fix a problem,
we'll ask for them privately.

## What happens next

Every new issue is labelled **needs-triage** until we've looked at it. We'll then
label it, reply with questions if needed, and close it once the fix is live in
production. You'll get GitHub notifications for each update on issues you open.

## Urgent problems

If you can't work at all (for example, nobody can sign in or save documents),
open a **Bug report** with severity **Blocking** and also contact the TOM support team directly.
